# 🏋️ Trénink – přestěhováno

Tréninkový deník i Claude Akademie teď žijí v repozitáři **[learning-apps](https://github.com/honzajscz/learning-apps)**.

- Trénink: https://honzajscz.github.io/learning-apps/trenink/
- Claude Akademie: https://honzajscz.github.io/learning-apps/claude-akademie/

Tento repozitář už obsahuje jen přesměrovací stránky pro staré adresy
(`/workouts/` a `/workouts/claude-akademie/`), aby nainstalované staré verze
dostaly novou adresu místo chyby. Data v prohlížeči (localStorage) jsou společná
pro celou doménu `honzajscz.github.io`, takže tréninky ani pokrok v kurzech se přesunem neztrácí.
